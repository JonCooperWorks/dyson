# HTTP Controller (`controller/http`)

## Overview
The HTTP controller hosts the embedded React web UI and exposes the JSON API and per-conversation Server-Sent Events stream. `HttpState` is the single shared object every route reads and every per-turn `SseOutput` writes into: live `Settings`, inbound auth, chat-history backend, feedback store, FIFO file/artefact stores, activity registry, SSE tickets, and per-chat `ChatHandle`s with broadcast channels and replay rings. Routing lives in `routes/`; the web UI source lives in `web/`.

## Invariants
- On a non-loopback bind an `auth` config is required; loopback binds default to `DangerousNoAuth` [mod.rs, config.rs:is_loopback_bind]
- `is_loopback_bind` accepts only parseable socket addresses with loopback IPs (`localhost:...` is rejected) [config.rs:is_loopback_bind]
- Per-chat queue capped at `QUEUE_CAP = 16` turns [state.rs:QUEUE_CAP]; SSE replay ring capped at 4096 events [state.rs:EventRing]
- File store keeps at most 64 entries, artefact store 32 (FIFO eviction) [stores.rs:FileStore, stores.rs:ArtefactStore::MAX_ARTEFACTS]
- Body caps: `MAX_TURN_BODY` 25 MiB, `MAX_SMALL_BODY` 16 KiB, `MAX_MIND_BODY` 4 MiB [wire.rs:MAX_TURN_BODY, wire.rs:MAX_SMALL_BODY, wire.rs:MAX_MIND_BODY]
- Files over 25 MiB are not inlined by `SseOutput::send_file` [output.rs:SseOutput]
- SSE tickets expire after 30 s [state.rs:HttpState::mint_sse_ticket]
- At most `MAX_CONCURRENT_CONNS = 1024` connections [mod.rs:MAX_CONCURRENT_CONNS]; idle agents evicted after 30 min, swept every 5 min [mod.rs:AGENT_IDLE_EVICTION, mod.rs:AGENT_EVICT_SWEEP_INTERVAL]
- Responses carry `X-Content-Type-Options: nosniff`, `Referrer-Policy: no-referrer`, `X-Frame-Options: DENY`, and further security headers [responses.rs:apply_security_headers]
- Lock topology is documented per field; all `std::Mutex` users recover from poisoning with `into_inner()` [state.rs]

## Side Effects
- Binds a TCP listener (optionally TLS) and spawns per-connection tasks plus background idle-eviction tasks [mod.rs:HttpController]
- Enables the MCP elicitation UI broker (`skill::mcp::elicitation::enable_ui`) [mod.rs:HttpController]
- Persists files and artefacts (`*.body`, `*.meta.json`) under the controller data dir [stores.rs:FileStore, stores.rs:ArtefactStore]
- Pushes artefacts (base64 body) to a configured URL with bearer auth and a 10 s timeout [output.rs:SseOutput::send_artefact]
- Broadcasts SSE events to subscribed browsers [state.rs:ChatHandle::emit, subagent_events.rs:SubagentEventBus]
